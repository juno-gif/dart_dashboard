## Executive Summary

기업 전략기획팀은 DART, 네이버 금융 등 여러 소스를 수작업으로 방문해
데이터를 엑셀에 복붙하고 차트를 만드는 반복적이고 비효율적인 작업에
시달리고 있다. 이 제품은 DART OpenAPI로 상장사 재무 데이터를 자동 수집하고,
비상장사는 수기 입력으로 보완하는 내부 전용 웹 대시보드다. 전략기획팀이
기업 검색 즉시 5년치 P&L과 B/S 핵심 항목을 확인하고, 복수 기업 비교 차트를
자동 생성하며, 분석 세트를 저장·재사용·최신화할 수 있는 "팀의 기업 분석
라이브러리"를 지향한다. 결과물은 두레이 공유 링크 및 PPT export로 배포
가능하며, EBITDA·현금흐름 등 심화 분석은 재무팀 자체 툴과 역할을 분담한다.

## Core Vision

### Problem Statement

전략기획팀은 기업 실적 분석을 위해 DART, 증권사 앱, 유료 서비스를 수동
탐색하고 엑셀에 수작업으로 입력·시각화하고 있다. 동종업계 경쟁사 비교 및
투자 검토 대상 기업 분석 시, 경쟁사 3~6개 동시 비교, 최근 분기 누계 실적
파악, 비상장 스타트업 데이터 수집이 특히 시간을 많이 잡아먹으며, 완성된
분석을 팀과 공유하기까지 추가 가공 단계가 필요하다.

### Problem Impact

- 반복적인 데이터 수집·정리 작업이 전략 분석 본연의 업무 시간을 잠식
- 경쟁사 3~6개 비교 시 각 기업 페이지를 개별 방문해야 하는 비효율
- 비상장 스타트업의 경우 유료 서비스(NICE Bizline) 또는 구글링에 의존
- 분기마다 반복되는 분석을 매번 처음부터 다시 구성해야 하는 비효율
- 데이터 완성 후 두레이 업로드·PPT 작성까지 추가 가공 단계 필요

### Why Existing Solutions Fall Short

- **네이버 금융/FnGuide**: 기업별 개별 페이지 방문 필요, 세부 비용 항목
  미제공, 통합 비교 뷰 없음, 분석 저장·재사용 불가
- **NICE Bizline**: 유료, 팀 협업·공유 기능 없음, 사내 업무 플로우 미통합
- **DART 직접 방문**: 시각화·비교·저장 기능 전무, 수작업 의존

### Proposed Solution

DART OpenAPI로 상장사 재무 데이터를 자동 수집하고, 비상장사는 수기 입력으로
보완하는 내부 전용 웹 대시보드. MVP 재무 데이터 범위는 다음과 같다:

- **P&L**: 매출, 영업이익, 순이익, 주요 비용 항목(매출원가·인건비·지급수수료),
  사업부별 실적
- **B/S**: 자산, 부채, 자본, 현금성 자산

분석 세트(기업 묶음 + 항목 설정)를 저장하고 분기마다 최신 데이터로 자동
업데이트하는 "기업 분석 라이브러리"로 기능한다. 결과는 두레이 공유 링크 및
PPT export로 팀 내 배포. EBITDA·현금흐름 등 심화 재무 분석은 재무팀 자체
툴과 역할을 분담한다.

### Key Differentiators

- **자동화된 DART 수집**: 상장사 재무 데이터 즉시 조회, 수작업 불필요
- **통합 비교 뷰**: 3~6개 기업을 한 화면에서 동시 비교
- **세부 항목 지원**: P&L 세부 비용 + B/S 핵심 4항목(자산·부채·자본·현금성 자산)
- **기업 분석 라이브러리**: 분석 세트 저장·재사용·자동 최신화
- **비상장사 데이터 자산**: 수기 입력 DB가 쌓일수록 강해지는 팀 고유 자산
- **사내 업무 플로우 통합**: 두레이 공유 링크 + PPT export
- **명확한 역할 분담**: 전략기획팀(P&L + B/S 핵심) / 재무팀(심화 분석 자체 툴)

### Primary Users

#### 페르소나 1: 김지수 — 전략기획팀 주임/대리 (빌더: 핵심 분석 담당자)

**배경**
경력 3~5년차. 팀 내 실무 분석을 주로 담당한다. 엑셀은 능숙하게 다루지만
재무 전문가 수준은 아니다. 팀장 또는 실장의 탑다운 지시로 분석을 시작하는
경우가 대부분이며, 데이터 수집부터 PPT 초안 작성까지 전 과정을 담당한다.

**현재 고충**
- DART에서 연도별 보고서를 하나씩 열어 숫자를 복붙하는 데 1~2시간 소요
- 경쟁사 3~6개 비교 시 각 기업 페이지를 개별 방문하며 동일 작업 반복
- 비상장 스타트업은 NICE Bizline·혁신의숲·IR deck·구글링을 뒤지며 수집
- 분기마다 같은 기업 세트를 처음부터 다시 구성해야 하는 반복 작업
- 데이터 수집 후 엑셀 차트 → PPT 가공까지 추가 작업 필요

**성공 비전**
"경쟁사 5개를 선택하면 비교 차트가 바로 나오고, 지난번 분석 세트를
불러와 최신 분기 데이터로 업데이트한 뒤 PPT export 버튼 하나로 끝낼 수 있다면
하루 종일 걸리던 작업이 1~2시간 안에 끝날 것 같아요."

**배경**
경력 8~10년차. 팀 전체 분석 방향 설정, 결과물 최종 검토, 실장 보고용 PPT

**현재 고충**
- 팀원이 데이터 수집에 시간을 너무 많이 써서 인사이트 도출이 부족
- 보고 직전 숫자 오류 발견 시 재작업 필요
- 과거 분석 자료를 찾아서 업데이트하는 과정이 비효율적

**성공 비전**
"팀원이 데이터 수집 시간을 줄이고, 그 시간을 인사이트 도출에 쓸 수 있으면
좋겠어요. 팀이 쌓아온 분석 세트가 라이브러리처럼 관리되면 신규 프로젝트를
시작할 때 훨씬 빠르게 시작할 수 있을 것 같아요."

데이터 신뢰성이 핵심 요건이다.

### User Journey

#### 전형적인 분석 사이클

**1. 트리거**
실장 또는 팀장이 지시 ("A사 및 경쟁사 3개 실적 비교해봐") →
김지수가 분석 작업 시작. 자체 판단으로 시작하는 경우도 있으나 탑다운이 다수.

**2. 기업 세트 구성**
- 상장사: 기업명 검색 → DART 자동 수집
- 비상장사: NICE Bizline·혁신의숲·IR deck 등에서 수집 후 수기 입력
- 기존에 저장된 공용 분석 세트가 있으면 불러와서 재사용

**3. 분석 및 검토**
- P&L 추이 확인 (연도별 매출·영업이익·순이익·주요 비용·사업부별)
- B/S 핵심 항목 확인 (자산·부채·자본·현금성 자산)
- 경쟁사 비교 차트 자동 생성
- 팀장이 결과 검토 후 방향 조정 지시
- 주 1~2회 수시 검토 및 업데이트

**4. 보고 준비**
- PPT export → 팀장 최종 검토 → 실장 보고용 PPT 완성
- 두레이에 분석 링크 아카이브
- 경영진 보고 시 PPT 앞부분에 대시보드 화면 포함, 실장이 라이브 인터랙션

**5. "Aha!" 순간**
- 기업명 검색 즉시 5년치 P&L·B/S가 한 화면에 시각화될 때
- 경쟁사 5개를 선택하자마자 비교 차트가 자동 생성될 때
- 지난 분기 분석 세트를 불러와 최신 데이터로 한 번에 업데이트할 때

**6. 장기 정착**
팀이 누적한 비상장사 데이터와 공용 분석 세트 라이브러리가 쌓이면서,
신규 프로젝트 시작 시 기존 자산을 활용하는 것이 자연스러운 루틴이 됨.
